# Breadcrumb

Ancestor trail above the page content, rendered by WooCommerce.

**When to use:** Use on pages nested below a section index (products, categories, product detail). Absent on the homepage and top-level landing pages.

Observed **11** time(s) across **11** page(s).

## Rules and gotchas

- Rendered by WooCommerce, so the markup is a flat `nav` with `/` separators rather than a list.
- Absent on the homepage and on top-level landing pages — 11 of 15 templates.

## Canonical markup

Real theme class names, so a prototype inherits the theme CSS. Imagery is a placeholder — FormFactor's own photography and logos are never redistributed from this repo.

```html
<nav class="woocommerce-breadcrumb">
  <a href="/">Home</a> / <a href="/products/">Products</a> / Probe Cards
</nav>
```
