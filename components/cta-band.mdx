# CTA band

A rounded, shadowed panel holding a centered heading and a grid of two or three calls to action.

**When to use:** Use to close a page, or between content sections, when you want to offer the reader two or three next steps of equal weight.

Observed **5** time(s) across **4** page(s).

| Variant | Background | Text | Radius | Count | Pages | Example classes |
|---|---|---|---|---:|---:|---|

## Rules and gotchas

- The panel itself carries the utility classes `radius shadow` — 30px radius plus the site's one real elevation (`rgba(0,0,0,0.2) 0 4px 15px`).
- Two or three items per row via `ul.cta-grid`; each `li` uses `flow` for vertical rhythm.

## Canonical markup

Real theme class names, so a prototype inherits the theme CSS. Imagery is a placeholder — FormFactor's own photography and logos are never redistributed from this repo.

```html
<section class="cta-box">
  <div class="wrapper">
    <div class="cta-box__content flow radius shadow">
      <div class="cta-box__heading flow center"><h2>Ready to talk?</h2></div>
      <div class="cta-box__body">
        <ul class="cta-grid">
          <li class="flow flow-space-600">
            <p>Talk to an applications engineer about your test challenge.</p>
            <a class="btn btn-primary" href="/contact">Contact sales</a>
          </li>
        </ul>
      </div>
    </div>
  </div>
</section>
```
